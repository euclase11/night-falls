# Сайт для ролевой

Статический сайт на чистом JavaScript, сборка не нужна.

## Запуск на своём компьютере

Страницы загружают данные из JSON, поэтому двойной щелчок по index.html не сработает. Нужен локальный сервер:

- VS Code: расширение Live Server, затем "Open with Live Server".
- или в папке проекта: `python -m http.server 8000`, затем открыть http://localhost:8000

## Что где менять

- js/config.js: название сайта, путь к картинке карты.
- assets/: положите сюда свою карту и поменяйте mapImage в js/config.js.
- data/*.json: персонажи, события, поселения, прочее.
  - world: "real" (реальный мир) или "afterlife" (посмертие).
  - у событий scope: "global" или "local", order задаёт порядок на таймлайне.
  - у поселений x и y в процентах от ширины и высоты карты, color и number задают точку.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. Settings, затем Pages, источник: ветка main, папка root.
3. Через минуту сайт появится по ссылке вида https://ваше-имя.github.io/название-репозитория/

## Дальше

Файл js/store.js отвечает за получение данных. Для добавления материалов прямо на сайте его заменим на работу с Firebase, остальной код почти не изменится.
